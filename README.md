# 💰 Projeto Fin-Flow

Aplicativo mobile para controle de finanças pessoais.

<img src="/Assets/images/logo-FinFlow.png" width= "100" height="100">

## 📌 Objetivo

Auxiliar usuários no controle de receitas, despesas e metas financeiras.

## 🚀 Funcionalidades

- Cadastro de usuário
- Registro de receitas e despesas
- Relatórios financeiros
- Definição de metas
- Exportação de dados (PDF/CSV)

## 🛠 Tecnologias

- AsciiDoc
- Android (Planejado)
- Kotlin ou Flutter
